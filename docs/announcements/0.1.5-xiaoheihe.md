# 长页 0.1.5 更新：给小米用户多一个免费超长截图选择

做长页的出发点很简单：想为小米用户补上一个免费、简洁的超长截图工具选择。

我自己有保存超长页面的需求，希望有个干净的小工具，能自动滚动、接成长图，再完整导出 PNG。于是就做了长页，也把源码公开了。

这次 0.1.5 主要更新了三件事：

- **采集更稳**：针对小黑盒正文中滚动后容易停住的问题，优化了选区、画面稳定检查和接缝匹配，减少不必要的暂停。
- **支持深色模式**：主界面、悬浮控制和选区跟随系统切换，晚上使用更协调。
- **重新整理界面**：采用更简洁的卡片布局，把开始采集、最近任务和导出入口放得更清楚。

长页目前免费开源、无广告、无网络权限，图片只保存在本机。功能仍然围绕竖向长截图展开。

目前要求 Android 15 及以上，主要在 Redmi K70E 上实测。高度重复的评论区仍可能触发暂停；遇到问题，欢迎带上手机型号、系统版本和具体页面反馈。

源码仓库：[Lawnisomer/longpage](https://github.com/Lawnisomer/longpage)
