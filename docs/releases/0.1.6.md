# 长页 0.1.6 · 采集策略测试版

本次发布重点处理相邻帧重叠不足与顶部动态导航栏干扰，同时包含此前本地 0.1.5 的原生卡片界面和系统明暗主题支持。

## 更新内容

- 正常拖动距离从有效滚动区域的约 60% 缩短至 40%，拖动时间仍为 450ms，缓慢收尾仍为 180ms。
- 稳定、静止、粗细匹配与原像素精修统一排除选区顶部 10% 的证据；首帧保留完整选区，后续只追加底部新增条带。
- 位移搜索上限按有效正文高度计算，保留至少约 24% 正文重叠；继续保留可信度、唯一性与固定底栏检查。
- 主界面、悬浮控制及选区支持系统明暗主题，使用原生卡片布局。
- 包名、签名与任务格式沿用既有版本，不增加依赖或权限。版本为 0.1.6 / versionCode 7，最低 Android 15 / API 35。

## 验证与已知限制

- 36 项 JVM 匹配与稳定性检查通过，含屏蔽前后各 100 对同排版异内容负例。
- Redmi K70E / Android 16 动态顶栏样本连续采集 10 帧、1220 × 10660；14 个完整面板均为 720px，PNG 导出与分块的最大单通道差为 1。
- 小黑盒公开文章短测保存 5 帧、1220 × 5694 后，仍在正文接缝歧义处暂停。此版本不保证解决所有页面的稳定性问题；顶栏超出屏蔽范围、重复正文、大范围动画仍可能需要重选区域或结束保存已有内容。
- 本轮未重测 Android 15 真机；Android 15 既有记录来自 0.1.4 的模拟器验证。未进行超长任务、JMComic2 或 PicACG 实测。

APK 已关闭调试能力，并使用既有本机签名。请从本 Release 下载 `LongPage-0.1.6.apk`；`SHA256SUMS.txt` 用于校验下载完整性。

完整验证范围见 [VALIDATION.md](https://github.com/Lawnisomer/longpage/blob/v0.1.6/VALIDATION.md)。
